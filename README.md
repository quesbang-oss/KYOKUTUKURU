# Voice DAW（SAKKYOKU）

声を録音して楽器にし、GarageBand のように曲を作って **MP3 で書き出せる** スマホ向け作曲アプリです。
Web 技術で作ったアプリを Capacitor で Android アプリ（APK）にしています。通信なし・完全オフラインで動きます。

## 使い方（曲を作って MP3 にするまで）

1. 画面下の **⏺** を押す → カウントダウン後に録音開始 → もう一度 **⏺** で停止。録音はそのトラックに自動で配置されます。
   - 録音先のトラックは、各トラック見出しの **⏺** ボタンで選べます。
   - 他のトラックにクリップがあれば、それを聞きながら重ね録りできます。
2. **▶** で再生、**■** で停止。タイムラインの空き部分を指でなぞると横に動きます。
3. 下のタブで素材（Samples）、エフェクト、楽器（鍵盤・パッド・Voice Chop）、ドラム（Sequencer）、ミキサーを使えます。
4. 右上の **⇩ 書き出し** → 形式は **MP3**（初期値）または WAV → 「書き出す」。
   Android では共有シートが開くので、ファイルへの保存・LINE/Drive などへの送信ができます。

## APK を作る

### 方法A：GitHub Actions（おすすめ・手元の環境構築は不要）

1. このフォルダを GitHub のリポジトリに push する（`main` ブランチ）。
2. リポジトリの **Actions → Build Android APK** が自動で動く（手動なら「Run workflow」）。
3. 完了後、実行結果の **Artifacts → voice-daw-apk** から `app-debug.apk` をダウンロードする。

### 方法B：自分の PC でビルド

必要なもの：Node.js 22 以上、JDK 21、Android SDK（Android Studio を入れれば揃います）。

```bash
npm ci
npm run apk        # → android/app/build/outputs/apk/debug/app-debug.apk
```

Android Studio で開く場合は、先に `npm ci && npm run sync` を実行してから `android/` フォルダを開いてください。

## スマホへのインストール

`app-debug.apk` をスマホに送り、タップしてインストールします（「提供元不明のアプリ」の許可が必要）。
初回の録音時にマイクの許可を求められるので「許可」を選んでください。

## 注意

- 出力される APK は **デバッグ署名** です。自分のスマホへの導入用で、Google Play での公開には署名付きリリースビルドが別途必要です。
- 保存データ（プロジェクト・素材）はアプリ内に保存されます。アプリを削除すると消えるため、大事な曲は MP3 / WAV やプロジェクトファイル（📁 → 名前を付けて保存）で書き出してください。

## 開発

```bash
npm run dev    # http://localhost:8080 でブラウザ確認（PC・スマホ幅どちらも可）
npm test       # 音声処理・書き出しの自動テスト
```
